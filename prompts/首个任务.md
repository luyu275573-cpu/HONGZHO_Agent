# 鸿智 Agent · 首个任务 Prompt（复制给 Codex / Claude / DeepSeek）

你是「鸿智 Agent」（HarmonyOS 原生一句话个人助理）的主编码智能体。
开始前先读：`AGENTS.md`、`docs/design.html`、`docs/development-doc.md`、`docs/agent-spec.md`。

## 任务
完善「对话主页」：消息气泡 + 工具调用过程卡片（ToolCallCard）+ 底部输入栏，当前已有基础骨架（entry/src/main/ets/pages/Index.ets）。

## 具体要点
1. 消息气泡：用户右侧（天青渐变）、AI 左侧（面板色），圆角 12。
2. 工具调用过程卡片 ToolCallCard：展示「🧠 规划 / ⚙️ 工具调用 / ✅ 结果回填」三段，
   状态色按 DesignTokens 约定（规划=SKY / 执行=STATUS_RUN / 完成=STATUS_DONE）。
3. 底部输入栏：语音按钮 + 输入框 + 发送按钮。
4. 先用本地假数据模拟「一句话建提醒」的完整过程（用户消息 → 工具调用卡片 → AI 回复）。
5. 颜色引用 `common/DesignTokens.ets`，禁止硬编码。

## 约束（违反即打回）
- ArkTS + ArkUI，API 12+（本机 SDK API 26）；禁止引入未列出的三方库。
- 颜色/圆角/间距引用 DesignTokens，禁止硬编码。
- 权限（INTERNET/MICROPHONE）已在 module.json5 声明，本任务不接真实模型/语音，先跑通 UI。
- 增量修改，不改动 EntryAbility / hvigor 配置。
- UI 对照 `docs/design.html` 第一、二屏「对话主页 / 工具调用轨迹」。

## 验收标准（做完对照勾选）
- [ ] `hvigorw assembleHap` 构建通过（或 DevEco Studio 构建通过）
- [ ] 对话主页显示用户气泡 + ToolCallCard + AI 回复，三段状态色正确
- [ ] 底部输入栏可输入、发送后追加消息
- [ ] 颜色引用 DesignTokens，无硬编码
